# Immunostrat V9 - Menaces avancees

V9 ajoute des menaces biologiquement inspirees, mais encore simplifiees pour le gameplay.

## Ajouts

- Champignons : foyers lents qui produisent des spores.
- Parasites : mini-boss rares, robustes et inflammatoires.
- Cellules anormales : menace interne mieux geree par NK et T cytotoxiques.
- Opportunistes : pression secondaire dans les zones affaiblies.
- Carte du corps : nouveaux presets locaux et generation selon la difficulte.
- Mode infini : phases tardives enrichies et mutateur `Menaces avancees`.

## Patch V9.1

V9.1 transforme les familles V9 en sous-types plus clairs :

- bacteries : cocci rapides, bacilles intestinaux, biofilm, lentes resistantes, toxiques ;
- virus : respiratoire rapide, cytolytique, latent/reactivation, immuno-evasif ;
- champignons : levure opportuniste, moisissure a spores, champignon cutane lent ;
- parasites : helminth-like mini-boss, protozoaire sanguin, larve migratrice ;
- cellules anormales : discrete, proliferative, inflammatoire, invasive ;
- opportunistes : bacterie secondaire, flare fongique, reactivation virale, infection mixte.

Chaque profil important porte maintenant des champs de preparation V11 :
`visualIdentity`, `behaviorProfile`, `difficultyTier`, `strengths`, `weaknesses`,
`realLifeInspiration`, `scienceDescription` et `simplificationNote`.

## Limites volontaires

V9 ne code pas de faction pathogene jouable, pas de traitement specifique complet,
pas d'oncologie realiste, pas de vraie immunologie antiparasitaire et pas de polish
visuel final. Ces points restent pour V9.5, V10.5 ou V11 selon la roadmap.

## V9.2 - Fin de partie normale

La carte du corps est maintenant le mode normal fini :

- victoire : organisme stabilise pendant plusieurs tours ;
- defaite : effondrement global, infection systemique, inflammation excessive ou trop de regions critiques ;
- score : stabilisation, regions sauvees, batailles locales, sante globale et rapidite ;
- sauvegarde : meilleurs resultats separes du mode infini ;
- mode infini : reste un mode survie sans victoire finale obligatoire.
