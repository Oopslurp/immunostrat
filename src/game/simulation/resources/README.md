# Resources

Les trois ressources de combat se regenerent pendant une bataille :

- l'ATP fournit un revenu stable pour garder la production d'unites active ;
- les cytokines ont un faible revenu de base, renforce par la pression infectieuse ;
- les antigenes ont un revenu de secours lent une fois les cellules dendritiques
  debloquees, avec un petit bonus pour les trois premieres cellules dendritiques.

Les revenus utilisent les multiplicateurs de carte, de mode et de difficulte. Le
revenu antigenique passif doit rester nettement inferieur aux livraisons actives
de debris afin que la collecte dendritique conserve son importance tactique.
