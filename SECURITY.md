# Politique de sécurité

## Versions prises en charge

La branche principale et la dernière release publiée reçoivent les correctifs
de sécurité.

## Signaler une vulnérabilité

N'ouvrez pas d'issue publique contenant les détails d'une vulnérabilité ou un
secret. Utilisez la fonction **Security > Advisories > Report a vulnerability**
du dépôt GitHub. Si cette fonction n'est pas encore disponible, contactez le
propriétaire du dépôt en privé.

Indiquez si possible :

- la version ou le commit concerné ;
- les étapes de reproduction ;
- l'impact observé ;
- une proposition de correction éventuelle.

Les sauvegardes du jeu restent dans le navigateur et aucune donnée de santé
réelle ne doit être saisie dans l'application.
